# 🧮 Project Calculator

A simple Python-based calculator designed to perform basic arithmetic operations. This project demonstrates fundamental Python programming concepts and beginner-level problem-solving skills.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⌨️ User input handling
- 🐍 Beginner-friendly Python implementation

## 🛠️ Technologies Used

- **Language:** Python
- **Concepts:** Variables, operators, conditional statements, and user input

## ⚙️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Ankitatan/Project_Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Project_Calculator
   ```

3. Run the Python file:

   ```bash
   python calculator.py
   ```
